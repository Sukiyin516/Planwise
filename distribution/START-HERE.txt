留白 Planwise — 小組試用版 v5.1（2026-11-06）

需要：Mac 或 Windows、Python 3.9 以上、一般瀏覽器。
只用 Python 標準函式庫，無需 pip install，啟動後可離線使用。
本壓縮包沒有內置 Python；未安裝請先到 https://www.python.org/downloads/
Windows 安裝時勾選 Add Python to PATH。

1. 先完整解壓到有寫入權限的資料夾，例如桌面。不要在 ZIP 預覽內啟動。
2. Mac：雙擊 Start-Mac.command。
   Windows：雙擊 Start-Windows.bat。
3. 瀏覽器自動開啟；若未開啟，複製終端機顯示的網址。
4. 啟動視窗需保持開啟。關閉程式時，在視窗按 Ctrl+C。

Mac 若不允許雙擊，請在終端機輸入 bash 後加一個空格，
把 Start-Mac.command 拖入終端機，按 Enter。
如有系統安全提示，先確認檔案來源，再透過右鍵「打開」查看可用選項。

首次啟動為空白資料，先在「事項」輸入課程／工作及睡眠／私人時間，
再新增有 DDL 的任務或長期目標。所有時間以半小時為單位。
沒有設定的時間視為空檔；沒有預設的上班或睡眠時間。

想試用示例：雙擊 Sample-Mac.command 或 Sample-Windows.bat。
示例與個人資料分開保存。示例日期以首次啟動當天計算，之後不自動重設。

資料在解壓資料夾：
- my-data.json：自己的任務、事項、私人時間與行程。
- sample-data.json：示例模式的資料。
關閉程式後可複製這些檔案備份。每位組員各自保存，沒有同步功能。
不要同時開兩個使用同一份資料的程式，以免互相覆蓋修改。
這份包不含開發者的個人／示例紀錄、不含 APK。

手動啟動（在此資料夾的終端機）：
Mac：python3 -B launch.py
Windows：py -3 -B launch.py
示例：在指令最後加 --demo

第三頁「事項與設定」可切換繁／簡／英，也可導出或導入 JSON 備份。
導入會取代目前資料，先驗證並保留原檔備份；不是資料合併。
長期目標累計投入會填滿圓點；可修改參考工時，填滿不等於完成。
重複支援每工作日／每假日，內置香港 2026–2027 公眾假期。
手機預設單日，週總覽完整顯示七天，可點日期展開。

進一步說明見 docs/；原始碼在 app/。
測試：python3 -B -m unittest discover -s app -v
Windows 可將 python3 改為 py -3。

驗證範圍：Mac 已驗證解壓後程式啟動、網頁資源與資料寫入；
Windows 啟動檔已作靜態檢查，尚未在 Windows 實機驗證。

固定事项不能拖动，可编辑系列或只移除某一次。前移建议可稍后处理，不会阻止记录投入或修改任务。
